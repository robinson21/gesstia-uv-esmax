# UV Laboral Esmax

Web estática de **gestión de riesgo por radiación ultravioleta (SST)** para Esmax.

- Fuente: **Dirección Meteorológica de Chile (DMC)** (radio 26 estaciones, observado + pronóstico).
- Deploy del dato: Cloudflare Worker `dmc-uv-proxy` (https://dmc-uv-proxy.robinson-armijo.workers.dev).
- Funciones: geolocalización → estación DMC más cercana → pronóstico + medidas preventivas; explorar todas las estaciones.
- Base legal: D.S. 594, Art. 109 (protección solar obligatoria 1 sept–31 mar, 10:00–17:00).
- Marca: Esmax · GesstIA (SST).

URL publicada: https://robinson21.github.io/gesstia-uv-esmax/
